# Kali Linux

## Hot Keys / Shortcuts

### 🧭 Core GNOME / Workspace Navigation

#### Switch between **Workspaces**

- **Super + Page Up** → Workspace above
    
- **Super + Page Down** → Workspace below
    
- **Ctrl + Alt + ↑ / ↓** → Move between workspaces (classic GNOME style)

#### Move a window to another workspace

- **Shift + Super + Page Up / Page Down**
    
- **Shift + Ctrl + Alt + ↑ / ↓**

### 🪟 Window Management

#### Switch between open windows

- **Alt + Tab** → Cycle through applications
    
- **Alt + \`** (grave) → Cycle windows of the _same_ application

#### Close / Minimize / Maximize

- **Alt + F4** → Close window ☠️
    
- **Super + H** → Minimize window
    
- **Super + ↑** → Maximize window
    
- **Super + ↓** → Restore / Unmaximize / Minimize

#### Snap windows (tiling)

- **Super + ←** → Snap left
    
- **Super + →** → Snap right

### 🚀 Application Launching & System Control

#### Open Activities Overview (GNOME brain center)

- **Super** (Windows key)

From here you can:

- Type app names
    
- Switch workspaces
    
- Drag windows between workspaces

#### Open commonly used apps

- **Super + Enter** → Open **Terminal** (Kali default)
    
- **Super + F** → Files (Nautilus)
    
- **Super + B** → Toggle browser (usually Firefox if pinned)
    
- **Alt + F2** → Run command dialog

#### Lock / Log out

- **Super + L** → Lock screen 🔒
    
- **Ctrl + Alt + Del** → Log out menu

### 🖥️ Terminal & Shell Productivity

Inside **Terminal** (Bash / Zsh / Fish):

- **Ctrl + Shift + T** → New tab
    
- **Ctrl + Shift + W** → Close tab
    
- **Ctrl + Shift + C / V** → Copy / Paste
    
- **Ctrl + L** → Clear screen
    
- **Ctrl + D** → Exit shell
