## Netrw : Built-in File Browser

Before plugins, you should learn netrw (Neovim’s built-in file browser).

To open it, First open `nv` Or `nvim`, Command Line Mode Type below command:

**Type exactly like semicolon`:Ex` Or  `:Explore`**

This opens a file browser inside Neovim, no plugin.

**Basic navigation** :

- `Enter` → opens a file
-  ( Double Dot `../` )→ go up directory
- `R` → rename
- `D` → delete
- `%` → new file
- `d` → new directory

Keymaps.nvim :

- Prefix: `CTRL + a`
